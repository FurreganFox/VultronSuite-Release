# Vultron Suite

Public repository for **bug reports**, **feature requests**, the
**changelog**, and **installer downloads** for Vultron Acquire and
Vultron Visualize.

> This repository does not contain the applications' source code -
> only issues, releases, and documentation.

## Downloads

The current installer is available under [Releases](../../releases).

## Report a bug / suggest a feature

Please use [Issues](../../issues) - there are templates for bug
reports and feature requests.

## User guide

How to install and operate Vultron Acquire and Vultron Visualize:
[docs/USER_GUIDE.md](./docs/USER_GUIDE.md).
